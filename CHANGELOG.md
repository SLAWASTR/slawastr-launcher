# Changelog

All notable features and changes of **slawastr's launcher** are documented here.

## 1.1

### Features
- **Liquid glass interface.** Apple TV-inspired frosted glassmorphism with configurable real-time blur and highlights.
- **Floating settings card.** 400dp side-docked glass panel with 24dp pill actions and instant live previews.
- **Optimised TV home screen.** Fast, distraction-free layout with custom favorite apps and continue-watching media shelf.
- **Game consoles and HDMI inputs.** Dedicated status tiles with official branding for PlayStation, Xbox, Switch and TV sources.
- **Smart wallpaper engine.** Local photo folders, USB drives, phone Wi-Fi upload via QR code, and vertical alignment controls.
- **Custom monochrome & color icons.** Brand palette or unified monochrome styling with continuous HSV hue and brightness tuning.
- **Dark All-Apps drawer.** High-contrast backdrop behind the full application grid for maximum legibility on OLED and MiniLED.
- **Pin layout protection.** 4-digit PIN security to safeguard custom layouts from unintended changes.
- **Zero bloat & instant boot.** Framework Views only, under 1.4 MB APK, zero background telemetry, sub-100ms startup.
