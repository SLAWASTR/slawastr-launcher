# 🧹 Гайд по безопасной очистке (Debloat) Android TV / TCL

Данное руководство объясняет, как безопасно отключить предустановленный рекламный мусор, трекеры и фоновые процессы на телевизорах TCL под управлением Google TV / Android TV без потери стабильности и риска окирпичивания.

---

## ⚠️ Почему очистку лучше делать вместе с ИИ (AI-ассистентом)

> [!IMPORTANT]
> **Не используйте слепые пакетные bash-скрипты из интернета!**  
> Производители (особенно TCL) связывают важные функции (пульт ДУ, переключение входов HDMI, голосовой ввод, CEC-управление консолями, ТВ-тюнер) с неочевидными системными пакетами. Если случайно отключить зависимость SystemUI или настроек экрана — телевизор уйдет в циклическую перезагрузку (Bootloop).

**Преимущества работы через ИИ:**
1. **Анализ списка пакетов устройства в реальном времени:** ИИ считывает `pm list packages` именно вашей ревизии прошивки и выявляет безопасные кандидаты на отключение.
2. **Контроль зависимостей:** ИИ проверяет, не привязан ли сервис к звуковому движку, Wi-Fi или управлению питанием.
3. **Безопасный метод `disable-user`:** Вместо жесткого `pm uninstall` используется `pm disable-user --user 0`, что позволяет вернуть любой процесс одной командой `pm enable` без сброса настроек.
4. **Мгновенный откат при любых сбоях:** Если после отключения пакета что-то пошло не так, ИИ сразу откатит изменения обратно.

## 🛠️ Подключение к телевизору через ADB

1. На телевизоре откройте:  
   **Настройки → Система → Об устройстве** и нажмите **7 раз** на пункт *«Сборка ОС Android TV»*, пока не появится сообщение «Вы стали разработчиком».
2. Перейдите в **Настройки → Для разработчиков**:
   - Включите **Отладка по USB** (USB debugging).
   - Включите **Беспроводная отладка** (Wireless debugging).
3. На компьютере выполните:
   ```bash
   adb connect <IP_ТЕЛЕВИЗОРА>:<ПОРТ_БЕСПРОВОДНОЙ_ОТЛАДКИ>
   ```
4. Для постоянного подключения без смены портов переведите отладку на порт 5555:
   ```bash
   adb tcpip 5555
   adb connect <IP_ТЕЛЕВИЗОРА>:5555
   ```

## 🚫 1. Блокировка стандартного лаунчера Google TV

Чтобы оставить **только `slawastr's launcher`** и исключить вылеты на рекламно-нагруженный рабочий стол Google:

```bash
# 1. Назначаем slawastr's launcher (dev.plume) эксклюзивным владельцем роли Home
adb shell cmd role add-role-holder --user 0 android.app.role.HOME dev.plume

# 2. Отключаем стоковый лаунчер Google TV
adb shell pm disable-user --user 0 com.google.android.apps.tv.launcherx

# 3. Отключаем резервный экран первоначальной настройки
adb shell pm disable-user --user 0 com.google.android.tungsten.setupwraith
```

## 🗑️ 2. Безопасные для отключения сервисы TCL и Google

### Реклама, промо-блоки и рекомендации:
```bash
# Рекомендации и промо-каналы Android TV Home
adb shell pm disable-user --user 0 com.google.android.tvlauncher
# Системные предложения и реклама
adb shell pm disable-user --user 0 com.google.android.tvrecommendations
```

### Телеметрия, трекеры и лишние сервисы TCL:
```bash
# TCL Браузер и портал контента (тяжелый фоновый процесс)
adb shell pm disable-user --user 0 com.tcl.browser
# TCL Домашний медиацентр / магазин рекламы
adb shell pm disable-user --user 0 com.tcl.home
# Сервис сбора статистики и аналитики TCL
adb shell pm disable-user --user 0 com.tcl.useragreement
# Встроенные промо-приложения и демо-режим
adb shell pm disable-user --user 0 com.tcl.magictv
adb shell pm disable-user --user 0 com.tcl.store
```

## 🔄 Восстановление (Откат в исходное состояние)

Если вы решите вернуть любой сервис или стандартный лаунчер:
```bash
# Включение стандартного лаунчера Google
adb shell pm enable com.google.android.apps.tv.launcherx
adb shell pm enable com.google.android.tungsten.setupwraith
```
